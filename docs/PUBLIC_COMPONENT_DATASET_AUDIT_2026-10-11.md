# Public PCB component data audit — 2026-10-11

This audit distinguishes usable component-instance annotations from related PCB data that cannot serve as per-component segmentation ground truth. Public data may support generic visual pretraining, but it does not establish the identity, reference designator, pinout, or 3D location of parts on a Tokito specimen.

## Local Tokito mask readiness

`python scripts/build_component_review_backlog.py` generates `data/photo-model/component-review-backlog.json`. On 2026-10-11 it found 427 source mask records across 14 unique frames (401 unique image/instance IDs). All image hashes verified; zero frames met the explicit complete-visible-instance training gate. Partial frames remain appropriate for the ignore-aware diagnostic trainer, not ordinary YOLO background-supervised training.

The source annotation files cover ESP32, ESP8266/ESP-12E, NXP and Ultimainboard. Their 398 reviewed masks are heavily correlated by specimen/capture session and have unresolved visible objects. The 70 recently ingested iQOO gallery files include original captures and crop variants. Six full originals now have board/view reviews, but none has complete component masks; all 70 remain excluded from model training and evaluation. Do not synthesize labels from source BOM/placement records or infer visible part identities from text that cannot be read in the image.

## Next data actions

1. Export and archive the CC BY 4.0 Roboflow instance-segmentation version with attribution and a file-level checksum manifest; inspect polygon quality, class duplicates, and train/validation provenance before use.
2. Request FPIC access codes from its authors if it offers meaningful additional instance masks and compatible reuse terms.
3. Use external masks only for generic component-appearance pretraining. Keep Tokito class, specimen identity, source/refdes joins, pins, and evaluation split separate.
4. Review complete visible component masks on Tokito capture groups and obtain independent specimens/sessions before selecting a model for AR or reporting precision/recall.
