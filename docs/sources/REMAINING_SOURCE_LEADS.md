# Remaining source leads

## ESP8266 photographed wide CH340-style clone

A paid community STEP listing exists at https://craftedtechengineering.com/product.html?id=3d-cad-model-lolin-nodemcu-esp8266-v3-development-board-ch340g-wider-base-standard-step-file . Listing price observed 2026-10-09: PHP 175. Not purchased, downloaded or verified. Listing claims a wide-base LoLin V3 / CH340G model; this does not establish a match to the photograph. Confirm actual clone dimensions and revision before considering purchase.

Free library source https://github.com/Jefferson-Lopes/kicad-libs explicitly lists NodeMCU LoLin without a 3D shape. Its NodeMCU v1 models are a different reference variant. No complete, exact photographed-clone STEP model has been verified.

## NXP complete board 3D

Official Rev C design archive includes Allegro BRD, OrCAD DSN, BOM, manufacturing files and schematic/fabrication PDFs. It contains no complete board STEP/GLB. Official community enclosure STEP files are preserved as enclosure geometry only. Searches to date have not established a downloadable complete board STEP. An export from the source CAD tool or a manufacturer-supplied model remains a possible route.

## Manufacturing sources

Exact-revision Ultimaker Gerber exports and exact ESP32 clone manufacturing files remain unverified. Native Ultimaker Altium PCB and ESP32 community-reference KiCad PCB are preserved, but exports should come from compatible CAD tools and undergo source-layout review. Do not use differently revised sources as exact manufacturing ground truth.

## PCB-Vision

Official repository https://github.com/hifexplo/PCBVision links Zenodo record 10617721 and Rodare record 2704. Metadata, licensing and remote member inventory are preserved. File-data access stalled across the tested official endpoints. No RGB image/label acquisition is complete. A working source download or user-provided local archive path would unblock acquisition. No process is currently running.
