# Source files by photographed board

The dataset uses one labeling rule across all five families: identify the board first, then source-match each visible part, then number/contact-map only what can be oriented in the photo. A source package is not automatically the exact design of a photographed clone.

| Photographed family | Sources present in this repository | What remains unmatched or unavailable |
| --- | --- | --- |
| ESP32 30-pin DevKit (variant unknown) | DOIT pinout reference; community-clone KiCad PCB/schematic/BOM and generated Gerber/drill plus board-only STEP/GLB; external PCB-Vision training set | Community clone is a comparison design, not verified as the photographed board. The exact clone maker, PCB revision, fitted USB-UART/PMIC parts and MPNs remain unconfirmed.
| ESP8266 NodeMCU-style ESP-12E clone (variant unknown) | NodeMCU open-hardware Altium schematics/PCB, BOM data and upstream Gerber archives V1–V4; reference pin catalog | The photographed board is a wider CH340-style clone, while the preserved NodeMCU reference is a different USB-UART variant. Do not transfer designators or MPNs until geometry is registered.
| Ultimaker Ultimainboard 2.1.4 | Matching-version Altium PCB and schematics; structured design records; generated Gerber/drill and board-only STEP/GLB; 574/574 source designators match the structured source | Photo-to-PCB registration is still needed to map the complete board. DRC and import warnings remain documented; generated files are analysis references, not fabrication-ready.
| NXP FRDM-MCXN236 | User-downloaded official Rev C design ZIP, native Allegro BRD, OrCAD project/schematic, BOM and netlists; structured Rev C component/net/pin records; generated Gerber/drill and board-only STEP/GLB | The photo identifies MCXN236 but the physical PCB revision is unverified. Keep Rev C part numbers as candidates until marking and geometry confirm the installed part. Official archive has no separate Gerber/STEP/GLB; local exports are conversions with recorded DRC/import warnings. Exclude the separate MCXN947 package.
| Raspberry Pi 3 Model B v1.2 | Official revision 1.2 reduced schematic and mechanical PDF/DXF; reviewed J8 physical numbering and net labels | No exact electrical PCB project, full BOM or official Gerber/STEP/GLB is in this corpus. The mechanical files are not an electrical PCB design. Do not invent missing files or train source-only component boxes as visual labels.

The individual packages and hashes are indexed by [`source-bundles.json`](../source-bundles.json), [`docs/sources/README.md`](sources/README.md), and [`data/board-sources/CAD_EXPORTS.md`](../data/board-sources/CAD_EXPORTS.md). The NXP Rev C archive and component extraction details are in [`data/board-sources/nxp-frdm-mcxn236/PROVENANCE.md`](../data/board-sources/nxp-frdm-mcxn236/PROVENANCE.md) and its `structured-rev-c` folder.

These gaps explain why the generic detector cannot truthfully label exact parts or pins. The dataset has 240 partial major-component boxes and 165 partial photo-located contacts before the new 33-photo intake; it does not yet have exhaustive instance labels across all images. Preserve candidate, source-linked, printed-alias, and visually verified identities as distinct statuses.
